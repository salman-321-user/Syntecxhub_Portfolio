M Salman Haider - Portfolio Website
A modern, responsive portfolio website showcasing frontend and Android development skills with a unique dual-theme (light/dark) design system.

https://assets/contact.png

✨ Features
Dual Theme System - Seamless light/dark mode toggle with persistent state

Fully Responsive - Optimized for all devices from mobile to desktop

Modern Design - Gradient accents, glassmorphism effects, smooth animations

Interactive UI - Hover effects, transitions, and engaging micro-interactions

Project Showcase - Display of signature work with live demos and code links

Skills Grid - Visual representation of technical expertise with tags

Contact Section - Integrated contact form and social links

🛠️ Technologies Used
Frontend
HTML5 - Semantic structure with accessibility in mind

CSS3 - Custom properties, Flexbox, Grid, animations

Google Fonts - Inter & Outfit font families

Design System
CSS Custom Properties for theming

Glassmorphism effects with backdrop-filter

Gradient accents and dynamic shadows

Mobile-first responsive approach

📱 Responsive Breakpoints
1200px+ - Large desktops

901px - 1200px - Small desktops/tablets landscape

701px - 900px - Tablets portrait

481px - 700px - Large phones

361px - 480px - Small phones

≤360px - Extra small devices

Landscape mode - Optimized for phone landscape orientation
